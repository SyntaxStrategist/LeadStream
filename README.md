## 🚀 Déploiement sur GitHub Pages

### Étapes de déploiement :

1. **Initialiser le repository Git**
```bash
git init
git add .
git commit -m "Initial commit: Portfolio one-pager for Leadstream"
```

2. **Créer un repository sur GitHub**
   - Aller sur github.com
   - Créer un nouveau repository (ex: `leadstream-portfolio`)
   - Ne pas initialiser avec README, .gitignore ou license

3. **Pousser le code**
```bash
git remote add origin https://github.com/VOTRE-USERNAME/leadstream-portfolio.git
git branch -M main
git push -u origin main
```

4. **Activer GitHub Pages**
   - Aller dans Settings > Pages
   - Source: Deploy from a branch
   - Branch: main / (root)
   - Cliquer sur Save

5. **Accéder au site**
   - Votre site sera disponible à: `https://VOTRE-USERNAME.github.io/leadstream-portfolio/`
